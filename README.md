# Employee Management System

## Project Overview
The Employee Management System is a web-based application developed using Python, Flask, and MySQL. It helps manage employee records and department information.

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Chart.js

## Features
- Add new employees
- Edit employee details
- Delete employee records
- Search employees
- View employee profiles
- Department management
- HR dashboard
- Average salary calculation
- Department-wise employee chart

## Database
Database Name: emplo_man

Tables:
- Employees
- Departments

## How to Run
1. Install Python.
2. Install required packages:
   pip install flask mysql-connector-python python-dotenv
3. Configure database credentials in the .env file.
4. Run the application:
   py app.py
5. Open http://127.0.0.1:5000/ in your browser.
